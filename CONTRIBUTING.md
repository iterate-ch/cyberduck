# Contributing to Cyberduck

Pull requests are welcome! Whether it is a bug fix, a new protocol implementation, an improvement to an existing
feature or a translation, we appreciate your help in making Cyberduck better.

## Contributor License Agreement

Before we can accept your contribution, you need to sign the Contributor License Agreement (CLA) for this repository.
The CLA confirms that you have the right to submit your work and grants the project the rights needed to distribute it,
including as part of Cyberduck and [Mountain Duck](https://mountainduck.io/).

You only need to sign once. Pull requests from contributors who have not signed the CLA cannot be merged.

Read the [Cyberduck Contributor Agreement](https://gist.github.com/fe9eea5febecc8526b747836b039f42c) and sign it
through [CLA assistant](https://cla-assistant.io/iterate-ch/cyberduck), or by following the prompt the CLA assistant bot
posts on your pull request.

## Submitting a Pull Request

1. Open an [issue](https://github.com/iterate-ch/cyberduck/issues) first for larger changes or new features to discuss
   the approach.
2. Fork the repository and create a branch from `master`.
3. Keep the change focused. Follow the code style of the surrounding code.
4. Add or update tests covering your change.
5. Make sure the build and tests pass.
6. Open a pull request against `master` describing what the change does and why.

See [AGENTS.md](AGENTS.md) for instructions on building and testing the project.

## Localizations

Translations are managed on [Transifex](https://app.transifex.com/cyberduck/cyberduck/dashboard/) and should not be
submitted as pull requests.

## Reporting Security Issues

Please do not report security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
